# Learning Management System

A Spring Boot REST API project for managing Students, Courses, Instructors, and Enrollments.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- REST API
- Git & GitHub

## Features

- Student CRUD Operations
- Instructor CRUD Operations
- Course CRUD Operations
- Enroll Student Into Course
- Get Courses By Student ID
- Exception Handling
- Layered Architecture (Controller, Service, DAO, Repository)

## API Modules

### Student APIs
- Add Student
- Update Student
- Delete Student
- Get Student By ID
- Get All Students

### Instructor APIs
- Add Instructor
- Update Instructor
- Delete Instructor
- Get Instructor By ID
- Get All Instructors

### Course APIs
- Add Course
- Update Course
- Delete Course
- Get Course By ID
- Get All Courses

### Enrollment APIs
- Enroll Student Into Course
- Get Courses By Student ID

## Database

PostgreSQL database is used for data storage.
